# UN655 NFC 工厂发卡工具 — 使用说明书（草案）

版本：需求草案（无软件安装包前）  
适用系统：Windows 7 / 8 / 10 / 11  
配套设备：已烧录 Phase2.1 发卡固件的 MH2020C 读卡器（`NTAG_PROVISION_ENABLE=1`）  
通讯：串口，命令 `0x5d`，写入 NDEF 文本后由读卡器派生密钥并设密  

---

## 1. 能做什么

| 功能 | 说明 |
|------|------|
| 批量发卡 | 将「物料号 + ID号」写入 TAG 的 NDEF，并由读卡器完成一卡一密设密 |
| 导入清单 | 支持 Excel / TXT / CSV |
| 防重复 | 已成功发出的 ID 不能再发到其它卡；作废后也不释放 |
| 记录 | 成功记录 SN、物料号、ID、操作员工号、时间 |
| 手动输入 | 需密码解锁后才能用手输物料号/ID |
| 密钥备案 | 仅登记本厂密钥文件信息，**不在 PC 上计算/下发密钥** |

写入 TAG 的文本格式：

```text
MN:123456789
ID:A001
```

- 物料号：9 位数字  
- ID号：4 位数字或字母

## 2. 安装与一键部署

正式发布提供 `Setup.exe`（工程内 `setup\build_setup.ps1` 生成）：

1. 双击 `UN655_NFC_发卡工具_Setup_*.exe`  
2. 若提示缺少 .NET Framework 4.7.2，按提示打开微软下载页安装（Win7 常见）  
3. 安装完成，桌面 / 开始菜单出现「UN655 NFC 发卡工具」  
4. 用 USB 连接读卡器，设备管理器确认 COM 口  

发卡记录库在 `%LocalAppData%\UN655\PC_NfcWriterTool\data\`，**卸载软件不会删除该库**。  

也可直接运行 Release 绿色目录（exe + dll + x86/x64），但仍可能需自行安装 .NET。

---

## 3. 每天开工

1. 打开软件，输入**操作员工号**，进入系统  
2. 选择正确 **COM 口**，波特率 **115200**，点「打开」  
3. 状态显示「已连接」后再发卡  
4. （可选）工具 → 密钥文件备案，选择本厂 `Kf/D` 说明用 txt（仅追溯）  

---

## 4. 导入待发清单

1. 文件 → 导入清单  
2. 选择 CSV / TXT / XLSX（推荐 `templates\发卡导入模板.csv`）  
3. 查看预检：格式错误、库内重复、文件内重复、队列已有会标出  
4. 点「仅导入合法行到队列」（**不会**自动开始发卡）  
5. 若队列非空，确认后追加到队尾；选「否」取消导入（不清空队列）  
6. 自动发卡进行中不可导入，请先暂停  

### 模板格式

表头两列（必须一致）：

| 物料号 | ID号 |
|--------|------|
| 123456789 | A001 |
| 123456789 | A002 |

- **CSV/TXT**：UTF-8（可带 BOM），逗号分隔，首行为表头。  
- **XLSX**：用 ExcelDataReader 读第一个工作表前两列；可用 Excel 打开 CSV 后「另存为 xlsx」。  
- 同一物料号可对应多个不同 ID；每个 ID 全局只能成功发行一次。  
- 导入来源标记为「导入」。

模板路径（工程内）：

`templates\发卡导入模板.csv`  
`templates\发卡导入模板.txt`  
（xlsx 可选，列名与 CSV 相同）

## 5. 自动批量发卡

1. 确认队列中有待发条目  
2. 点「开始自动发卡」  
3. 将空白（或允许重发策略下的）NTAG213 放在读卡器上  
4. 成功：界面显示成功，自动准备下一条；拿开卡再放下一张  
5. 失败：查看原因（无卡、通讯超时、设密失败等），可重试或跳过  

**注意：**

- 卡需已有 NDEF 区域（CC=`E1`）；纯白卡需先格式化（当前读卡器 provision 不负责从零格式化）  
- 读卡器须为工厂发卡固件；现场量产读卡固件应关闭 provision  

---

## 6. 手动输入模式

1. 工具 → 手动输入模式  
2. 输入密码：`12345678`  
3. 填写物料号、ID号 →「加入队列」或「直接发卡」  
4. 用毕请「关闭手动模式」  

---

## 7. 查询、作废、导出

1. 打开「发卡记录」  
2. 可按 SN / 物料号 / ID / 工号筛选，并按状态选择「全部 / 成功 / 已作废」
3. **作废**：确认后需输入作废密码（默认 `12345678`）；标记该条为已作废；该 **ID 永远不能再发给任何新卡**
4. **导出**：按钮仍显示「导出Excel」，实际写出 **UTF-8 BOM CSV**（`.csv`），列为 SN、物料号、ID号、工号、发卡时间、状态；最多 500 条（与查询上限相同）。主菜单「文件 → 导出记录」导出当前库全部筛选（空条件，上限 500）。  

---

## 8. 常见问题

| 现象 | 处理 |
|------|------|
| 打不开串口 | 检查 COM、占用、线缆；关闭其它串口工具 |
| 一直等待放卡 | 确认天线、卡类型为 NTAG213 |
| 提示 ID 重复 | 该 ID 已在本地库（含已作废）；换新 ID |
| 设密/认证失败 | 检查读卡器是否发卡固件、密钥是否与产线一致 |
| Win7 无法运行 | 安装 .NET Framework 4.7.2 |

---

## 9. 职责划分（勿混淆）

| 谁 | 做什么 |
|----|--------|
| PC 工具 | 队列、防重、日志、工号、导入导出、串口发 `0x5d`+NDEF |
| 读卡器固件 | 读 SN、用内置 Kf/D 派生 PWD/PACK、写保护、自检 |
| PC 密钥 txt | 仅备案，不参与写卡运算 |
