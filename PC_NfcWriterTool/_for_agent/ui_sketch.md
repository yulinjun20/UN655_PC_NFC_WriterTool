# PC NFC 发卡工具 — 界面草图

适用范围：Win7/8/10/11 工厂单机版。技术建议：C# WinForms + .NET Framework 4.7.2。  
本文仅草图，不含代码。

---

## 1. 启动 / 操作员登录

```
+----------------------------------------------------------+
|  UN655 NFC 工厂发卡工具                              [_][X]|
+----------------------------------------------------------+
|                                                          |
|           操作员工号:  [______________]                  |
|                                                          |
|           [  进入系统  ]                                 |
|                                                          |
|  提示：工号将写入每条发卡成功记录。                        |
+----------------------------------------------------------+
```

规则：工号非空才能进入；本班次内显示在主界面状态栏。

## 2. 主界面（日常发卡）

```
+------------------------------------------------------------------+
| 文件(F)  工具(T)  帮助(H)                              [_][□][X] |
+------------------------------------------------------------------+
| 串口:[COM3 ▼] 波特率:115200  [打开] [关闭]  状态:●已连接        |
| 操作员: ZhangSan    本班成功:12  失败:1  队列剩余:35             |
+------------------------------------------------------------------+
| 当前待发                                                         |
|   物料号: 123456789          ID号: A001                          |
|   队列进度: 3 / 38                                               |
|                                                                  |
|   +---------------------------+                                  |
|   |     请放卡 / 等待中…      |     [开始自动发卡]               |
|   |     大字状态区            |     [暂停]                       |
|   +---------------------------+     [跳过本条]                   |
|                                                                  |
| 最近结果                                                         |
|   时间       SN              物料号      ID    结果              |
|   09:41:02   0454EADA591Dxx  123456789   A001  成功              |
|   09:40:51   044AEADA591Dxx  123456789   A002  失败:认证失败     |
+------------------------------------------------------------------+
| 密钥备案: key_factory_v1.txt (已加载·仅备案) | 手动模式:锁定     |
+------------------------------------------------------------------+
```

交互要点：
- **开始自动发卡**：循环「等卡 → 发 0x5d(NDEF) → 记库 → 下一条」
- 成功：绿灯/大字「成功」，队列下移，ID 写入本地库且不可再发
- 失败：红字原因，本条可重试或跳过（跳过不记成功、不占成功库；是否移出队列可配置，默认留在队列）

## 3. 导入任务（Excel / TXT / CSV）

```
+----------------------------------------------------------+
| 导入待发清单                                         [X] |
+----------------------------------------------------------+
| [选择文件…]  发卡导入模板.xlsx                           |
|                                                          |
| 解析结果: 共 120 行  合法 118  格式错误 1  库内重复 1     |
|                                                          |
| 预览表                                                    |
|  行  物料号      ID号   状态                             |
|  1   123456789   A001   待发                             |
|  2   123456789   A002   错误:ID已在库中                  |
|  3   12345       B1     错误:物料号非9位                 |
|                                                          |
| [仅导入合法行到队列]              [取消]                 |
+----------------------------------------------------------+
```

列名固定：`物料号`、`ID号`（见 templates\）。

## 4. 手动输入（密码门）

入口：工具 → 手动输入模式

```
+----------------------------------------------------------+
| 解锁手动模式                                         [X] |
| 密码: [********]  (默认 12345678)                        |
|              [确定]  [取消]                              |
+----------------------------------------------------------+

解锁后：
+----------------------------------------------------------+
| 手动输入                                             [X] |
| 物料号(9位数字): [_________]                             |
| ID号(4位):       [____]                                  |
| [加入队列]  [直接发卡]  [关闭手动模式]                   |
+----------------------------------------------------------+
```

---

## 7. 菜单结构

- **文件**：导入清单、导出记录、退出  
- **工具**：手动模式、密钥备案、串口设置、打开数据目录  
- **帮助**：打开说明书、关于  

---

## 8. 主流程（工厂）

1. 登录工号 → 打开串口  
2. （可选）备案密钥文件  
3. 导入 Excel/TXT → 预检 → 入队  
4. 开始自动发卡 → 工人连续放卡  
5. 收工导出本班记录
